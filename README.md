# SuperSay archive

SuperSay is an archived native macOS text-to-speech project built by Himansh
Mudigonda. This repository is preserved as source history only.

It has no supported download, release channel, installer, update path, product
analytics, or active development. The repository remains available under the
[MIT License](./LICENSE) that accompanied its original public source.

For the current product, visit **Voqora**.
