# Final legacy release

`v2.0.1` is SuperSay's final release. The release workflow is intentionally closed after its source, installer, and README are verified.

The legacy app does not offer self-updates. It directs people to Voqora's current GitHub release, project page, and product story, then asks them to remove SuperSay manually only after Voqora is confirmed working.

Do not add features or private successor work to this repository. New product releases belong to [Voqora](https://github.com/himudigonda/Voqora).
